# 官方评测平台操作手册（问题三）

> 适用：2026 CUMCM B 题问题三，程序 `T3_ga.py`。
> 本手册只讲**在官方测试平台上怎么跑**；算法与本地演练见 `reports/RESULTS_REPORT.md`。

## 0. 一句话说明

官方模拟器是 **Windows 桌面程序**（Wails + WebView2，Wine 下缺 WebView2 无法启动），
机器狗接口**只监听 127.0.0.1**。因此：**模拟器与 `T3_ga.py` 必须在同一台 Windows 机器上运行。**

```
Windows 机器
├── 官方模拟器（jammers-simulator-full.exe）  监听 http://127.0.0.1:2026
└── Python + T3_ga.py                        连 127.0.0.1:2026，跑完一局
```

## 1. 一次性准备（约 5 分钟）

### 1.1 模拟器

用**带运行时的 full 版**：`Jammers-simulator-full/jammers-simulator-full.exe`
（目录里的 `WebView2Runtime/` 是配套运行时；普通版要求系统已装 WebView2）。
解压后**整体保留目录结构**，模拟器会把登录与测试数据写进同级的 `JammersSimulatorData/`。
需要移动时整体移动。

### 1.2 Python 环境

1. 从 python.org 安装 **Python 3.12 或 3.13**（勾选 *Add python.exe to PATH*）。
2. 安装依赖：

```powershell
pip install numpy matplotlib
```

（`matplotlib` 只用于每局结束后的轨迹图；不装也能完成测试，只是不出图。）

### 1.3 拷贝程序文件

只需两个文件，放进同一个目录（例如 `D:\cumcm\`）：

```
T3_ga.py      主程序（含策略与 GA）
sim_api.py    HTTP 薄封装（必须与 T3_ga.py 同目录）
```

不需要拷贝 `jammers-py/`（那是本地演练用的复刻模拟器，官方平台上用不到）、
不需要 `results/`、`figures/`。

拷贝后自检（在 `D:\cumcm\` 下执行）：

```powershell
python T3_ga.py --help
```

能看到中文参数说明即表示环境正常。

## 2. 演练测试：务必先跑通

正式测试每题**只有 3 次机会**，且中止也占用一次。所以先用**不限次数**的演练测试把流程走通。

### 2.1 流程图

```
① 双击 jammers-simulator-full.exe
② 联网登录（首次需注册）
③ 选「问题3演练测试」→ 点开始 → 二次确认
④ 5 秒倒计时（此期间接口未开放，先别运行程序）
⑤ 界面提示接口已就绪
⑥ 运行：python T3_ga.py --base-url http://127.0.0.1:2026
⑦ 约 3 秒后程序自行结束；界面「指令与反馈」区可见完整请求/反馈
⑧ 记下界面显示的清除结果，与本程序输出的「清除 N 个」核对
```

### 2.2 具体命令

```powershell
cd D:\cumcm

# 推荐写法：以 UTF-8 输出，中文与符号显示最干净
python -X utf8 T3_ga.py --base-url http://127.0.0.1:2026

# 若模拟器设置里改过端口（默认 2026）：
python -X utf8 T3_ga.py --base-url http://127.0.0.1:8080
```

参数说明（一般都不用改）：

| 参数 | 默认 | 用途 |
| --- | --- | --- |
| `--base-url` | `http://127.0.0.1:2026` | 模拟器接口地址，改过端口才需要 |
| `--robot-id` | `202614023005` | 参赛队号，已内置，不用传 |
| `--save-dir` | `results/official/` | 结果输出目录 |
| `--quiet` | 关 | 只打印汇总，不打印过程明细 |
| `--no-plot` | 关 | 关闭每局结束后的轨迹图 |

### 2.3 预期输出

（下例是**实测样例**：用与官方同源的复刻模拟器走同一套官方模式代码路径跑出来的，连同 `results/official/` 一起留档，便于对照。）

```
==========================================================================

==========================================================================
连接模拟器 http://127.0.0.1:2026（robot_id=202614023005）
完成：清除 14 个，虚拟总时间 5008.1 s，平均 357.7 s/个，测向 158 次，清除动作 20 次
定位 GA：14 次训练（每代 80 个体），提前收敛 2/14 次（判据 适应度<1e-04），否则跑满 150 代...
路线 GA：覆盖路点巡回（8 点）8145 m → 8117 m，改进 0.3%
训练结果已保存：results/official/ga_training.json，results/official/ga_convergence.csv，results/official/episodes.csv
```

**核对要点**：本程序报的「清除 N 个」应与模拟器界面显示的清除结果一致；
`/enter`、`/exit` 各恰好 1 次。
注意「清除动作」次数会多于「清除」个数（上面例子 20 > 14）——多出来的几次是
`/clear` 返回 `no_target_in_range`（定位略有偏差），随后程序会沿实测示向度逼近重试，
这是正常策略行为，只多花虚拟时间（每次 3 秒）。

### 2.4 每局结束自动生成轨迹图

每跑完一局，程序会在 `<save-dir>/trajectory/` 下生成一张轨迹图 `ep01.png` 和同名轨迹表
`ep01.csv`，用来看清机器狗这一局怎么走的：行驶路径、每个测向点、每次清除尝试、成功清除落点，
以及干扰源真值及其 20 m 清除半径。

- 绘图在 `/exit` **之后**进行，**不占用 20 分钟现实时间预算**（单张约 1 秒）。
- 需要 `matplotlib`；**没装也不会影响测试**，只会提示一次并跳过绘图（`pip install matplotlib` 即可启用）。
- **官方模式的图上没有干扰源标记**：接口不返回真值，程序无从得知源在哪，所以那张图只有
  行驶路径、测向点、清除尝试与成功清除落点。要看源的位置请用本地演练（`--practice N`）。

### 2.5 耗时

程序现实耗时约 **3 秒**（现实限时 1200 秒，余量极大）。
「虚拟总时间」是虚拟世界里的时间（约 4000~6000 秒），现实中不等待。

## 5. 常见问题

**Q：程序报 `连接模拟器失败：Connection refused`**
模拟器没启动，或端口不是 2026。先启动模拟器并确认已在测试中。

**Q：程序报 `连接模拟器失败：Remote end closed connection without response`**
模拟器在运行，但**接口未开放**——典型原因：5 秒倒计时还没结束，或测试已经结束。
等界面提示接口已就绪后再运行程序。

**Q：界面上点了开始，但忘了运行程序**
25 分钟窗口超时会自动结束并标记超时退出。演练无所谓；正式测试则会浪费一次机会。

**Q：中文显示为乱码**
用 `python -X utf8 T3_ga.py`，或先在控制台执行 `chcp 65001`。
（程序已做兜底，即使字符编不出来也不会中断。）

**Q：能否在 Linux/Wine 上跑模拟器**
不行。实测 Wine 下报 `[WebView2 Error] no webview2 found`，窗口无法创建。
Linux 上的 `jammers-py` 是用于算法验证的复刻模拟器，**不能替代官方平台提交成绩**。

**Q：正式测试中网络抖动会不会中断**
机器狗接口是**本机回环连接**，不受外网影响。程序在异常时仍会尝试 `/exit`，
保证已清除的成绩有效；若接口整体关闭则本局结束。程序不自动重试，因此
**不要**在测试期间重启模拟器或切换网络。

## 6. 产出文件

跑完一局后 `results/official/` 下会有：

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `api_calls.jsonl` | 逐次 `/enter /measure /clear /exit` 的请求与原始响应 | **支撑材料**：题目要求程序自行记录指令序列与响应 |
| `trajectory/ep01.png` | 本局机器狗轨迹图 | 结果直观展示、论文插图 |
| `trajectory/ep01.csv` | 同名轨迹表（`step,x,y,kind`） | 与接口日志逐点对账 |
| `episodes.csv` | 本局战绩（清除数、虚拟时间、测向次数） | 论文与汇总表 |
| `ga_training.json` | GA 训练记录与最终解 | 论文「GA 训练过程」 |
| `ga_convergence.csv` | 逐代收敛曲线 | 论文收敛曲线图 |

官方模式下**拿不到干扰源真值**，因此定位误差等需要真值的指标留空——这是正常的，
成绩以模拟器判定为准。带真值的统计请用本地演练（`--practice N`，见 `RESULTS_REPORT.md`）。
