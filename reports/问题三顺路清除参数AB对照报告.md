# 问题三顺路清除参数 A/B 对照报告

对照对象：远程 `origin/master` 提交 `9aa31f3`（方差最优解的默认值更改）与本地 `master`（`097adb3`）的
问题三顺路清除参数默认值。远程改动已拉取到本地分支 `compare/remote-var-opt`（= `537e1b1`）。

## 1. 远程改动内容

`097adb3 → 537e1b1` 的**代码**差异只有 `cumcm/t3/config.py` 中 4 个常量（其余 29 个改动文件全是
结果图 `results/t3/scan/`、`results/t4/scan/`、`results/t4/trajectory/` 的新增产物）：

| 常量 | 变体 A：当前 `master` 默认 | 变体 B：远程「方差最优」默认 |
|---|---|---|
| `INLINE_R_MIN` | 700.0 | 296.3 |
| `INLINE_R_MAX` | 1700.0 | 1296.3 |
| `INLINE_NEAR_R` | 180.0 | 377.8 |
| `INLINE_MAX_MEC_R` | 75.0 | 103.0 |

远程提交注释自称：以「按干扰源个数 n 分组、组内取方差再对 n 求平均」为指标做三分式二分搜索，
搜索集 21 局（7 个 n × 3 seed）求最优；留出集 21 局（独立 seed）复核得到
「组内方差 25831.9 → 25413.9 s²、平均时长 3620.5 → 3608.4 s」，故采用方差最优值为默认。

两点需要说明：

1. 远程注释引用的搜索脚本 `t3_inline_param_search_var.py` **未入库**，其搜索/留出种子集也未记录，
   因此该结论无法按原协议复现。
2. 该改动**不影响问题四**：`cumcm/t4/config.py` 自带独立的 `INLINE_*` 一族常量（700/1700/180/75
   及内外圈专用值），不 import `cumcm.t3.config` 的这 4 个名字。远程新增的 T4 结果图与本次参数改动无关。

## 2. 复测协议

T3 的策略参数全部可由命令行覆盖，故两变体可在同一份代码上做**严格配对**（同 seed 的场景布局与
示向度噪声都由 seed 派生并逐字节固定，见 `cumcm/common/practice_arena.py`）：

- 每变体跑 3 个互不重叠的种子集共 **140 局**：对照集 seed 0..34、留出集 seed 200..234、
  独立集 seed 400..469；两变体同 seed 逐局配对；
- 练习模式 `--practice`（本地 jammers-py，官方模式只有 3 次机会、无真值、场景不可控，不能用于 A/B）；
- 确定性已验证：同参数同 seed 独立重跑两次，逐局字段完全一致（`virtual_time_s` 完全相同）；
- 方差指标沿用远程口径，另给出更稳的合并组内方差 `Σ(n_g−1)s_g² / Σ(n_g−1)`；
- 统计：逐局配对差的 95% bootstrap CI、Wilcoxon 符号秩检验；方差指标用**配对置换检验**
  （在每个 n 组内随机交换 A/B 标签，20000 次重排）。

## 3. 结果（合并 140 局）

| 指标 | A（当前默认） | B（远程默认） | 差 (B−A) |
|---|---|---|---|
| 局数 / 源数 | 140 / 1800 | 140 / 1800 | — |
| 未全清局数 | 0 | 0 | 0 |
| 清除比例 | 1.0000 | 1.0000 | 0.0000 |
| 虚拟时间均值 / s | 3665.95 | 3658.02 | **−7.93**（−0.22%） |
| 虚拟时间中位 / s | 3712.89 | 3708.35 | −4.54 |
| 虚拟时间标准差 / s | 285.18 | 290.12 | +4.95 |
| 虚拟时间最大 / s | 4291.68 | 4312.43 | +20.75 |
| 虚拟时间最小 / s | 2761.58 | 2558.52 | −203.06 |
| 方差指标·组内均值 / s² | 61354.2 | 62709.4 | **+1355.3** |
| 方差指标·合并组内 / s² | 64991.8 | 68350.7 | **+3358.9** |
| 里程均值 / m | 14319.5 | 14280.2 | −39.4 |
| 测向次数均值 | 122.19 | 122.32 | +0.14 |
| 定位误差均值 / m | 8.106 | 8.037 | −0.069 |
| 顺路清除命中 / 局 | 4.43 | 5.69 | **+1.26** |
| 顺路清除白跑 / 局 | 1.66 | 1.29 | −0.37 |

统计检验：

- 逐局虚拟时间差（配对 140 局）：均值 −7.93 s，95% bootstrap CI **[−33.3, +18.0]** s，
  中位 −12.4 s，B 更快 76 局 / A 更快 51 局 / 相同 13 局，**Wilcoxon p = 0.221**；
- 方差指标（远程口径，B−A = +1355.3 s²）：**置换检验 p = 0.833**；
- 方差指标（合并组内，+3358.9 s²）：**置换检验 p = 0.626**。

逐集合方向并不一致（这正是"更优"不成立的直接证据）：

| 集合 | 时间差均值 / s | 方差指标·组内均值 差 / s² | 方差指标·合并组内 差 / s² |
|---|---|---|---|
| I：seed 0..34（35 局） | −47.8 | **+26062** | +17925 |
| II：seed 200..234（35 局） | +17.9 | **−8602** | −6453 |
| III：seed 400..469（70 局） | −0.9 | **+779** | +4903 |

也就是说：换一个种子集，A、B 的"谁更优"就整体翻转。

## 4. 结论

1. **两套参数在本实现上的求解数据实质等价**：140 局全部满清除（1800/1800），平均虚拟时间相差
   7.9 s（0.22%，CI 跨 0，p = 0.22），里程、测向次数、定位误差几乎相同。
2. **远程主打的"方差更优"没有复现**：按其自身口径，B 的组内方差反而比 A 高 +1355 s²（p = 0.83），
   更稳的合并组内口径同样偏高（+3359 s²）；且逐集合符号在 +26062 / −8602 / +779 s² 之间翻转。
3. **该方差口径本身噪声过大，不宜作为调参目标**：同一对参数在不同种子集上取值 40k～107k s²
   （相差 2.6 倍），单一集合上的几万 s² 差异完全落在种子采样噪声内；远程以 3 seed/组搜索出的
   "方差最优"正是这种噪声的产物，与其注释中"以均值为指标会过拟合种子噪声"是同一个陷阱。
4. **远程参数的唯一稳定效应是"顺路多清一点"**：顺路命中 +1.26 个/局、白跑 −0.37 次/局（与
   `INLINE_NEAR_R` 由 180 提到 377.8 的设计意图一致），但这没有换来总时间或稳定性的实质改善。
5. 由数据看，两套参数**没有可分辨的优劣**：当前默认值无需改动，远程默认值也不会使结果变差。

**最终决定（2026-09-13，用户）：采纳远程默认值**（296.3 / 1296.3 / 377.8 / 103.0），
`master` 已 fast-forward 到 `537e1b1` 与队友保持一致（默认值生效后单局演练复核：seed 2032、
16/16 全清）。本报告作为参数敏感性证据保留：时间上远程值点估计快 0.2%（不显著），方差上略高
（亦不显著），两项都在种子噪声内，故该选择对成绩无实质影响。

## 5. 复现命令

```bash
# 变体 A（当前默认）
.venv/bin/python -X utf8 T3.py --practice 70 --seed 400 --no-plot --quiet --no-reuse \
  --robot-port 2111 --console-port 8091 \
  --inline-r-min 700 --inline-r-max 1700 --inline-near-r 180 --inline-max-mec-r 75 \
  --save-dir /tmp/ab_A

# 变体 B（远程默认）
.venv/bin/python -X utf8 T3.py --practice 70 --seed 400 --no-plot --quiet --no-reuse \
  --robot-port 2112 --console-port 8092 \
  --inline-r-min 296.3 --inline-r-max 1296.3 --inline-near-r 377.8 --inline-max-mec-r 103.0 \
  --save-dir /tmp/ab_B
```

`--seed` 改 0 或 200 即得另两个种子集；结果看 `--save-dir/t3_survey.json` 的 `episodes`（字段
`virtual_time_s`、`n_sources`、`clear_ratio`）。方差指标 = 按 `n_sources` 分组 → 组内样本方差 →
对各组求平均；配对置换检验 = 在每个 n 组内随机交换 A/B 标签后重算该指标。分析用
numpy + scipy（`scipy.stats.wilcoxon`），已装入 `.venv`。

注意：`--no-reuse` 与独立端口是必需的，否则会复用/抢占已在运行的 jammers-py 实例；官方模式
`results/t3/` 只保留最新一次运行，A/B 务必用独立 `--save-dir`。
